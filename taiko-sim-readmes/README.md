# Taiko Simulators' & Tools' Readme Files

* First created: 2025-04-15 (UTC+8)
* Last changed: 2025-04-18 (UTC+8)

An unofficial compilation of readme files of Taiko simulators and tools which are not directly browseable online.

Many files were not in UTF-8 character encoding. For each file in the Shift-JIS character encoding, a separate UTF-8 convert version is provided.

Shift-JIS to UTF-8 exporting script by IID: [`export-utf-8.sh`](export-utf-8.sh)
